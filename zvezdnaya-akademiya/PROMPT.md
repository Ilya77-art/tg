# «Звёздная академия»: промт и задачи для повторения проекта в новом дизайне

Файл описывает **суть** проекта: что он делает, из каких систем состоит, как проверить, что получилось. Внешний вид здесь намеренно не зафиксирован. Он задаётся в блоке «Дизайн-направление» и меняется под вашу идею.

## Как пользоваться

1. Установите скилы (один раз):
   - `npx skills add Leonxlnx/taste-skill`
   - `npx skills add emilkowalski/skill`
   - `npx mdskills install pbakaus/impeccable`
   - `/review-animations` запускайте сами в конце: ИИ его вызвать не может.
2. Вставьте в новый чат **«Короткий промт»** или **«Полный промт»**. Короткий подойдёт, если хотите, чтобы ИИ сам предложил решения. Полный нужен для точного повтора.
3. В блоке «Дизайн-направление» впишите свой стиль, референсы и палитру.
4. Работайте по **этапам из раздела 3**: один этап — один коммит и один отчёт со скриншотами. Не просите «сделай всё сразу», так лезет халтура.

## 1. Короткий промт

```text
Собери одностраничное приложение «Звёздная академия» — шахматную школу для детей 8–12 лет, на русском языке.
Один index.html + папка lessons/, чистые HTML/CSS/JS без сборки и фреймворков, работает офлайн, данные в localStorage.

Что внутри: хаб-дашборд; ученики (несколько профилей на одном устройстве, у каждого свои звёзды и прогресс); 9 интерактивных уроков;
шахматные задачи с подсказками и тремя звёздами за чистое решение; задачи Lichess (локальная выборка по темам и рейтингу);
ежедневные и недельные контракты, сундук; 24 медали с тремя ступенями; лавка с кейсами, редкостью и «гарантом»;
мастерская фигур (модель + скин + наклейки); профиль-витрина; журнал событий; экспорт/импорт JSON.
Главная фишка — «Путь чемпионов»: 12 шахматных ботов на карте из 4 миров, от лёгких с неполным комплектом фигур у соперника
до сильных с полным комплектом; собственный шахматный движок в Web Worker; звёзды за победы.

Дизайн: [ВПИШИТЕ СВОЙ СТИЛЬ]. Две темы (тёмная и светлая). Один сильный визуальный концепт, без «шаблонного ИИ-вида».
Анимации: быстрые, на transform/opacity, без декоративных бесконечных циклов, уважать prefers-reduced-motion.
Применяй скилы impeccable, design-taste-frontend, emil-design-eng. Каждый этап проверяй скриншотами в обеих темах и на 360/768/1440 px.
```

## 2. Полный промт

```text
РОЛЬ
Ты — старший дизайнер-разработчик. Делаешь законченный продукт, а не демо. Каждое решение объясняй одной строкой: что и почему.

ПРОДУКТ
«Звёздная академия» — шахматная академия для детей 8–12 лет. Тренер ведёт несколько учеников на одном устройстве или ребёнок занимается сам.
Ребёнок учится на уроках, решает задачи, играет с ботами и за всё получает звёзды. Звёзды тратятся в лавке на коллекционные предметы для своих шахматных фигур.
Цель игровой механики: регулярность занятий, а не «залипание». Поэтому нет таймеров-давилок, нет штрафов за пропуск, нет трат, нужных для прогресса.

ЖЁСТКИЕ ОГРАНИЧЕНИЯ
- Один index.html (CSS и JS внутри) + lessons/*.html. Без npm-сборки, без фреймворков, без внешних сервисов во время работы. Работает офлайн.
- Весь интерфейс на русском. Шрифты: кириллица обязательна.
- Хранение: localStorage с префиксом приложения; каждое чтение и запись в try/catch; приложение запускается и без хранилища.
- Экспорт и импорт всех данных одним JSON-файлом с проверкой формата и версией. Миграция старых данных без потерь.
- Адаптив: 360, 768, 1440 px без горизонтального скролла страницы; цели нажатия ≥ 44 px; шахматная доска остаётся квадратной и помещается в экран.
- Доступность: видимый фокус, контраст текста ≥ 4.5:1, управление доской с клавиатуры, aria-live для результатов хода, prefers-reduced-motion отключает движение (остаются затухания).
- Две темы: тёмная и светлая, переключатель в шапке, выбор запоминается, учитывается prefers-color-scheme.
- Размер: один файл ≤ 8 МБ с картинками (data URI), без внешних запросов на картинки.

ЭКРАНЫ (роутер по hash или состоянию, последний экран запоминается)
1. Хаб: сетка плиток разного размера. Приветствие и ранг ученика, «Путь чемпионов» (самая заметная плитка), задачи на сегодня и квесты (компактно), уроки, задачи, кейсы лавки, мастерская. Плитка не должна дублировать то, что уже видно на странице.
2. Ученики: список профилей, добавить, переименовать, удалить с подтверждением, выбрать активного. Звёзды и прогресс у каждого свои.
3. Уроки: 9 карточек (название, подзаголовок, прогресс, звёзды). Каждая карточка — одна кнопка. Урок открывается как отдельная HTML-страница с интерактивной доской, режимы: табло, предложение, лучший ход.
4. Задачи: шахматные упражнения с серией (вилки, связки, маты в два хода и т. д.), подсказка, проверка хода, звёзды 1–3 (3 — без подсказок и ошибок). «Задача дня».
5. Lichess: тренажёр по локальной выборке задач. Уровни по рейтингу: Пешка до 900, Конь 900–1200, Слон 1200–1500, Ладья 1500–1800, Ферзь 1800+. Группы тем: Маты, Тактика, Пешки и эндшпиль. Есть лимит звёзд за источник.
6. Путь чемпионов: см. отдельный раздел ниже.
7. Лавка: кейсы, полка предметов, ротация витрины, продажа дубликатов, коллекция с фильтрами по типу и редкости.
8. Мастерская: собрать фигуру из модели, скина и наклеек; предпросмотр на всех шести типах фигур; применить набор к доске ученика.
9. Профиль: «сцена» ученика (фигуры на подиуме), фон, рамка, титул, значки, карточки великих партий (переворот 3D), медали, статистика.
10. Журнал: хронология событий (звёзды, покупки, победы), фильтр, колонка «Путь».

СИСТЕМЫ
- Звёзды: источники хранятся раздельно по ключам (уроки по id, задачи, Lichess, квесты, боты). Баланс = заработано − потрачено. Лучший результат по каждому источнику засчитывается один раз (переигровка не фармится).
- Ранг ученика растёт от суммарных звёзд; повышение ранга — отдельный праздничный экран.
- Контракты (каждую неделю по три, по одному из трёх слотов: учёба, практика, исследование): «реши N разных задач», «N задач без подсказок», «N из серии X», «задача дня N раза», «изучи партию (карточка 3D)», «заработай N звёзд на уроках». Награда звёздами. Контракты никогда не требуют тратить звёзды.
- Недельный сундук: за выполненные контракты, выбор одной из трёх наград.
- 24 медали, у большинства три ступени (бронза, серебро, золото). Ряды: Тактик, Ученик, Путь и др. Медаль даёт только признание, не деньги.
- Редкость: обычный, необычный, редкий, эпический, легендарный, мифический (цвета и цены продажи заданы). «Гарант» после 10 кейсов без редкого.
- Кейсы: Мастерская (скины), Ковчег фигур (модели), Призма (редкие скины и модели), Капсула наклеек, Галерея фонов, Архив партий (карточки и значки), Ларец оформления (рамки, титулы, купоны тренера), Портал грёз (всё, только редкое). Шансы показываются честно прямо в карточке кейса. Подарок: «Стартовая капсула» за первый ход.
- Каталог предметов (≈130): типы skin, model, sticker, theme, card, badge, frame, title, coupon.
- «Купоны тренера» — награды-привилегии на живом занятии: подсказка в любой задаче, ход назад в партии с тренером, выбор задачи дня для группы, блиц с тренером, ведение разминки, выбор темы урока. Тренер подтверждает их вживую.
- Торжества: очередь тостов и медалей. Во время партии, урока и других «занятых» экранов торжества ждут и показываются после закрытия.

ФИГУРЫ, СКИНЫ, НАКЛЕЙКИ
- Все фигуры — SVG, читаются при 32 px. Силуэты различимы без цвета (конь не путается со слоном, ферзь с королём).
- Скины — материалы поверх силуэта (дерево, мрамор, лёд, лава, галактика, золото, голограмма, конфеты, джинса, дыня, желе, аврора, обсидиан и т. д.), через <defs> с паттернами и градиентами.
- Общий слой света и тени на всех фигурах; плоские скины (неон, пиксели) его отключают.
- Модели — персонажные наборы (лягушка, повар, снеговик, пчела, шут, паладин, робот, дракон, космос и т. д.): «под» и «над» слои для украшений.
- Наклейки (≈20): часы, сон, пазл, бум, мозг, призрак, медаль, планета и др.; ставятся на фигуру в мастерской.
- Плоская «простая» тема фигур остаётся доступной всем как базовая.

ПУТЬ ЧЕМПИОНОВ (главная фишка)
- Карта-тропа из 4 миров, 3 бота в каждом: Солнечная долина, Пиратская бухта, Ледяные вершины, Огненная цитадель. У каждого мира свой фон, палитра и декор. Следующий бот открывается победой над предыдущим.
- 12 ботов — персонажи со своим характером, репликами приветствия, победы и поражения. Сложность растёт по номеру, оформление тоже усложняется (простой пруд → цитадель).
- Лесенка комплекта фигур: у лёгких ботов у соперника неполный набор (только пешки, пешки и ладья, и так далее), у игрока всегда больше. Начиная с середины пути комплекты равны, на последних ботах — полный набор у обеих сторон. Перед партией показывать, кто чем играет.
- Звёзды за победу: 1–3 в зависимости от результата, умножаются на множитель мира (долина ×1, бухта ×2, вершины ×3, цитадель ×4); засчитывается лучший результат. Награда видна в карточке бота до игры.
- Игровой экран: доска, портрет и реплики соперника, взятые фигуры, ходы, подсказка «ход соперника думает» (без декоративных циклов), сдача, ничья, возврат хода. Фон партии — мир бота.
- Результат: экран победы или поражения, начисление звёзд, кнопка «следующий соперник».
- Прогресс хранится отдельно (ключ BOT), учитывается в «заработано», в журнале и в медали «Чемпион».

ДВИЖОК БОТОВ
- Свой шахматный движок на 0x88, запускается в Web Worker, собранном из текста <script> внутри страницы (без отдельных файлов).
- Поиск: альфа-бета, итеративное углубление, quiescence, таблица транспозиций, killer и history эвристики, расширение при шахе, оценка с материалом и PST (две фазы), «добивание» одинокого короля.
- Сила по уровням: глубина 1 → 7; доля «небрежных» ходов и шум оценки убывают; низкие уровни не видят мат в 1, средние видят, сильные не пропускают.
- Правила полностью: рокировка, взятие на проходе, превращение с выбором фигуры, пат, троекратное повторение, 50 ходов, недостаточный материал. SAN, FEN.
- Проверка перфтом: стартовая позиция 20 / 400 / 8 902 / 197 281; Kiwipete 48 / 2 039 / 97 862. Плюс тесты на мат в 1, мат в 2 и корректность взятий.
- Движок не блокирует интерфейс: ответ ≤ 3 с на самом сильном уровне.

ДИЗАЙН-НАПРАВЛЕНИЕ
Стиль: [ВПИШИТЕ: например «обсерватория ночью + чертёж на бумаге», «яркий детский пластилин», «комиксы 70-х» и т. п.]
Референсы: [ссылки или описание]
Палитра и типографика: [если есть, иначе предложи 2 варианта и выбери один с объяснением]
Требования независимо от стиля:
- Один сильный концепт, выраженный в токенах (цвет, радиусы, тени, отступы, движение). Все значения идут из токенов.
- Контраст и читаемость важнее эффектов. Текст на картинках — на плашке.
- Типографическая иерархия из 3–4 уровней, подписи не мельче 12 px.
- Анимации: ease-out кривая, 150–300 мс, только transform/opacity, нажатие кнопки = scale(.97), hover включается только на устройствах с мышью. Бесконечных декоративных циклов нет, допустимы только индикаторы загрузки и «думает».
- Запрещено: градиентный текст в обычных местах, стекло везде, цветная полоса сбоку у карточек, одинаковые карточки в сетке, эмодзи вместо иконок, лишние тени.
- Каждый экран имеет состояния: пусто, загрузка, ошибка, успех.

ПРОЦЕСС И ПРОВЕРКА
- Сначала короткий бриф и список токенов на согласование, потом код.
- Идти этапами из списка задач. После этапа — скриншоты (обе темы, 360/768/1440 px), короткий отчёт, коммит.
- Автотесты для шахматного ядра и движка; сквозные проверки (Playwright) для: игра с ботом до конца, начисление звёзд, покупка из кейса, смена темы, экспорт-импорт.
- Запустить impeccable detect и разобрать находки: исправить или объяснить, почему оставлено.
- Проверить prefers-reduced-motion: после включения не должно быть запущенных анимаций движения.
- Не выдумывать данные. Если чего-то не хватает (арт, тексты уроков) — оставить аккуратную заглушку и сообщить.
```

## 3. Задачи по этапам

Каждый этап: цель → что сделать → как принять. Следующий этап не начинать, пока предыдущий не принят.

### Этап 0. Бриф и подготовка
- [ ] Установить скилы (см. «Как пользоваться»), проверить, что ИИ их видит.
- [ ] Написать одним абзацем дизайн-концепт и 3 референса.
- [ ] Согласовать токены: палитра (обе темы), шрифты, шкала отступов, радиусы, тени, кривая и длительности анимаций.
- [ ] Решить, как будут получены картинки: генератор изображений (нужен ключ и доступ к домену API в настройках окружения) или векторная графика.
- **Принято:** на одной странице есть токены, макет шапки и одной плитки в двух темах.

### Этап 1. Каркас
- [ ] Один HTML-файл, токены в `:root`, тёмная и светлая темы, `color-scheme`, переключатель, запоминание.
- [ ] Шапка, навигация, роутер экранов, запоминание последнего экрана.
- [ ] Модуль хранилища с префиксом и try/catch; экспорт/импорт JSON с версией.
- [ ] Базовые компоненты: кнопка (4 состояния), плитка, карточка, модальное окно, тост, пустое состояние.
- **Принято:** переключение тем без вспышки, Tab проходит по всем элементам, на 360 px нет горизонтального скролла.

### Этап 2. Шахматное ядро и тесты
- [ ] Генерация легальных ходов, make/unmake, SAN, FEN, превращение, рокировка, на проходе, пат, повтор, 50 ходов.
- [ ] Перфт: старт 20 / 400 / 8 902 / 197 281; Kiwipete 48 / 2 039 / 97 862.
- [ ] Компонент доски: клик-клик и перетаскивание, подсветка ходов, последний ход, шах, выбор фигуры при превращении, управление клавиатурой, переворот доски.
- **Принято:** тесты зелёные одной командой; доска работает мышью, пальцем и клавиатурой.

### Этап 3. Данные и экономика
- [ ] Модель ученика: звёзды по источникам, потрачено, ранг, предметы, надетое, контракты, медали, журнал.
- [ ] Таблицы: редкость, кейсы и шансы, каталог предметов, контракты, медали (24), уровни и группы Lichess.
- [ ] Операции: заработать (лучший результат по источнику), купить и открыть кейс (с «гарантом»), продать дубликат, надеть, подтвердить купон тренера.
- [ ] Миграция старых данных.
- **Принято:** повторное решение той же задачи не даёт звёзд дважды; баланс не уходит в минус; импорт чужого файла отклоняется с понятной ошибкой.

### Этап 4. Экраны (по одному)
- [ ] Хаб, Ученики, Уроки, Задачи, Lichess, Лавка, Мастерская, Профиль, Журнал.
- [ ] 9 уроков как отдельные страницы с интерактивной доской и режимами табло, предложение, лучший ход.
- [ ] У каждого экрана есть состояния «пусто / загрузка / ошибка / успех».
- **Принято:** скриншоты каждого экрана в двух темах × три ширины; нет текста, вылезающего за плитки; плитки не дублируют информацию друг друга.

### Этап 5. Фигуры, скины, наклейки
- [ ] Базовый набор из 6 типов фигур, читаемый на 32 px; общий слой света и тени.
- [ ] 13+ скинов-материалов, 12+ моделей-персонажей, 20 наклеек.
- [ ] Мастерская: сборка, предпросмотр на всех фигурах, сохранение.
- [ ] Лист-превью «все фигуры × все скины» для проверки.
- **Принято:** никакие две фигуры не путаются в чёрно-белом режиме; скины не ломают силуэт; плоские скины не получают тень.

### Этап 6. Движок ботов
- [ ] Движок 0x88 в Web Worker из текста `<script>`.

## 7. Ошибки, на которые я уже наступал (заранее предупредите ИИ)

- Data-URI SVG ломается из-за символа `#`: кодируйте его (`%23`) или используйте `urllib.parse.quote`.
- В CSS-сетке высота в процентах у вложенного элемента раздувает картинку: используйте `display:block` и явные размеры.
- Тосты и медали во время партии перекрывают доску: проверка «занятого» экрана должна включать окно игры.
- Подписи на картинке неба нечитаемы: нужна тёмная плашка.
- Hover на сенсорных экранах «залипает»: включайте только под `@media (hover: hover) and (pointer: fine)`.
- Декоративные бесконечные анимации (дрейф фона, «дыхание» карточек, мерцание звёзд) утомляют и ломают reduced-motion: не добавляйте.
- Плитки с разным размером ломают текст: прячьте второстепенные подписи через container queries.
- Worker из текста `<script id="botEngine">`: читайте `textContent`, создавайте Blob и `new Worker(URL.createObjectURL(blob))`; тот же код не должен падать, если выполнится как обычный скрипт страницы.
- Генерация картинок: если окружение блокирует домен генератора, проверьте разрешённые домены и переменные окружения до начала работы, иначе этап 9 встанет.
